SMA 2.0 - ЗАПУСК В ОДИН КЛИК

Windows:  дважды щёлкните start.bat
Linux/Mac: ./start.sh      (или: python3 start.py)

Что произойдёт само:
 1. Установятся нужные библиотеки (нужен интернет при первом запуске).
 2. Запустится сервер SMA Core и откроется панель в браузере (http://localhost:8000).
 3. Если ESP32 подключён по USB - запустится bridge.py (порт определяется сам).
    Если ESP32 нет - запустится симулятор экипажа из 4 человек.
 4. Если процесс упадёт - он перезапустится. Воткнули или выдернули ESP32 -
    система сама переключится между мостом и симулятором.

Остановка: Ctrl+C в окне.

Требуется Python 3.9+ (галочка "Add Python to PATH" при установке).

Параметры:
  py start.py --sim          всегда симулятор
  py start.py --port 8080    другой порт сервера
  py bridge.py --port COM5   мост вручную с указанным портом

ИИ-помощник (Gemini): ключ уже лежит в файле .env (GEMINI_API_KEY=...).
  Подхватывается сам, ничего вводить в PowerShell не нужно. Сменить ключ - правьте .env.
  Без ключа панель работает, но отвечает по офлайн-справочнику.

ПУЛЬС С ТЕЛЕФОНА
  1. Телефон и компьютер в одной Wi-Fi сети.
  2. При запуске в окне напечатан адрес вида https://192.168.x.x:8443/pulse
     (он же показан в карточке "Пульс по камере телефона" на панели).
  3. Откройте его на телефоне. Браузер предупредит о сертификате:
     "Дополнительно" -> "Всё равно перейти" (сертификат свой, создан автоматически).
  4. Выберите астронавта, нажмите "Начать", закройте пальцем камеру и вспышку на 30 секунд.
  5. Результат появится на панели (источник: камера телефона) и заменит пульс
     устройства на 90 секунд. После замера ИИ даст короткую оценку.
  Если Windows спросит про доступ Python к сети - разрешите (частная сеть).
  Камеру можно использовать и на компьютере: карточка есть на главной странице.

ВИБРОМОТОР НА ESP32
  Уведомления панели (предупреждения, критические события, потеря связи,
  пульс с телефона, кнопка "Тест вибро на часах") мост bridge.py сам передаёт на ESP32
  командой NOTIFY - вибромотор на GPIO26 работает 2 секунды.
  Перепрошивать ESP32 не нужно: команда NOTIFY уже есть в SMA_ESP32.ino.
  Нужен ESP32 по USB (без него запускается симулятор, вибрации не будет;
  индикатор "часы: вибро готово" на панели показывает, что мост подключён).
